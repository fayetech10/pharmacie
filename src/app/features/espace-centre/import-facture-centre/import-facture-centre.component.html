Les prestations de votre logiciel, rapprochées des patients enregistrés par le BCSU.

  • Choisissez le régime et le mois, puis téléchargez le modèle : il liste déjà les patients enregistrés par le BCSU.
  • Complétez pour chacun la prestation, la quantité et le prix unitaire, puis déposez le fichier.

  • Après correction, réimportez le fichier : les prestations déjà importées sont remplacées, sans doublon.
